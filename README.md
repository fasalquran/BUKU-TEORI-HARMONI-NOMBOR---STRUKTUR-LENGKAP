# BUKU TEORI HARMONI NOMBOR - STRUKTUR LENGKAP

Selamat datang ke repositori rasmi untuk **Buku Teori Harmoni Nombor - Struktur Lengkap**, sebuah projek yang menggabungkan analisis numerikal Al-Quran, teori munasabah, dan aplikasi kosmik.

## Tujuan Projek
Projek ini bertujuan untuk:
- Menganalisis pola nombor dalam struktur Al-Quran (cth: bilangan ayat, surah, kekerapan perkataan).
- Menyusun teori munasabah untuk memahami hubungan tematik antara ayat dan surah.
- Mengaitkan penemuan ini dengan konsep kosmologi dalam Islam dan sains moden.

## Struktur Projek
- **Buku 1**: Teori Harmoni Nombor - Struktur Lengkap
- **Buku 2**: Teori Munasabah dan Aplikasi Kosmik (dalam pembangunan)
